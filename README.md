# GlitchOfHands

GlitchOfHands is an AI character chat, roleplay, and multi-agent card simulation engine powered by React 19, TypeScript, Tailwind CSS, and Perchance plugins (`ai-text-plugin`, `text-to-image-plugin`, `kv-plugin`).

Built using the principles from the *React + AI Stack for 2026*, designed for high type safety, clean component boundaries, and lean runtime overhead.

## Architecture

- **Core**: React 19 + TypeScript
- **Styling**: Tailwind CSS (v4)
- **Bundling**: Vite + `vite-plugin-singlefile` (compiles to self-contained `dist/index.html` ready for Perchance deployment)
- **Live Perchance Generator**: [perchance.org/glitchofhand](https://perchance.org/glitchofhand#edit:collab=Z4gQbylwtIzJIrqiJ68L)

## Quick Start

```bash
npm install
npm run dev      # Local development server
npm run build    # Bundles single-file dist/index.html
```
